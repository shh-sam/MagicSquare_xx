**MagicSquare_1004 — 세션 3 워크북** (Mom Test 결과 반영)

### 1) 주제 한 문장

4×4 부분 마방진을 채운 뒤, **가로·세로·대각 합이 34인지 검증하고**, 합이 맞지 않을 때 **어느 줄이 틀렸는지 바로 판정**할 수 있는지 확인한다.

### 2) R-G-I-O

| 항목 | 내용 |
|------|------|
| **Role** | 4×4 부분 마방진을 손·코드로 맞추는 **학습자** |
| **Goal** | 손으로 “한 줄씩 다시 더하기”(~10분) 없이, **불일치 여부와 틀린 줄**을 재현 가능하게 판정 |
| **Input** | 4×4 격자 상태 (1~16 일부 채움), 목표 합 **34** |
| **Output** | 전 줄 일치 여부; 불일치 시 **틀린 행·열·대각**; **판정 결과** |

### 3) 성공 기준 3개

| # | 성공 기준 | 연결 증거 |
|---|-----------|-----------|
| 1 | 10선 합 검증 한 절차로 수행·기록 | 「가로세로대각합이 같은지 확인」 |
| 2 | 불일치 시 **어느 줄** 출력 | 「합이 안맞음」「한줄씩 다시 더해서 찾았어」 |
| 3 | 동일 격자 → 검증 결과 **재현** (Test Loop) | 「10분」「20분」 |

### 4) 표면 문제 — 하지 않을 것

- Solver·GridUI **프로그램을 만든다**를 문제 정의로 삼기
- 빈칸 자동 채우기·ECB 전체·UI 우선
- 합만 true/false, 틀린 줄 특정 미루기

### 8계층 (이번 세션)

| 계층 | 범위 |
|------|------|
| **Rule** | 1~16 각 1회, 4×4, 10선 합 = 34 |
| **Command** | `ValidateAllLines`, `ReportMismatchLines` |
| **(Skill)** | 줄 합 계산, 34 비교 (선택) |
| **Test Loop** | 맞음/틀림/틀린 줄 pytest |
